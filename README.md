# tmt

Splatoon 3 **12.0.0**（タイトル ID `0100C2500FC20000`、main ビルド `6cbb1669`、SDK `6A0A2600`）用の exlaunch modmenu。
Inkdraw v706 のソースをもとに作っています。機能は Inkdraw と同じで、見た目は別物です（平らな黒鉛色の半透明パネル、アイコンなしの番号付き一覧、ミント1色のアクセント、小さな tmt ロゴ）。

> **ソースは毎回このリポジトリに commit すること。** Inkdraw はバイナリしか push しておらず、v707〜771 のソースを失いました。

## 入れ方

| ファイル | 置き場所 |
|---|---|
| `subsdk9`（日本語版）または `subsdk9_en`（英語版を `subsdk9` に名前変更） | `sd:/atmosphere/contents/0100C2500FC20000/exefs/subsdk9` |
| 設定・画像・pchtxt など | `sd:/tmt/`（旧 `sd:/inkdraw/settings.json` は初回だけ自動で引き継ぎ） |
| 自動アップデート | 配信元は `raw.githubusercontent.com/tomatoo0609/tmt/main/update` に固定（Inkdraw の配信は見ない） |

ゲームのバージョンが 12.0.0 でないときは、ゲーム本体へのフックを一切入れません（落ちないように）。

## アップデートの配信

`update/version.txt` に 1 行ずつ `種類 版 バイト数 crc32(16進)`。種類は `tmt`（日本語版）と `tmt_en`（英語版）。
ファイルは `update/<種類>/<版>/subsdk9`。版の番号は必ず上げる（今は 102 = Ver.1.0.2）。
Inkdraw の `normal` / `en` の行は種類名が違うので、tmt は読みません。

## 名前の変更

設定した名前は `sd:/tmt/name.txt`（1 行目 ON=1/OFF=0、2 行目に名前）に保存されます。名前のフック（`nn::account::GetNickname`）は起動直後に入るので、
ゲームが最初に名前を読んだときから偽の名前が返り、オンラインのプレイヤー情報にも入ります。試合中・広場で変えた場合は、自分の画面の写しはすぐ書き換えますが、
ほかの人に確実に出すにはゲームの再起動が必要です。入力は通常のキーボード（かな・漢字変換あり）で、全角の英数字は半角に直し、Switch と同じ 10 文字までです。

## ビルド

```
cd build_normal
./q2.sh      # 日本語版 → subsdk9
./q2_en.sh   # 英語版  → subsdk9_en
```
clang++ / ld.lld / llvm 18 を使います。コンパイルに失敗したら `BUILD FAILED` で止まります（壊れた小さな subsdk9 を作らない）。
`obj/`・`obj_en/` の exlaunch ランタイム .o は事前リンク済みのものなので消さないでください。

## 11.3.0 → 12.0.0 の移植（済み）

- main の .text（フック・パッチ点 50 か所）: 位置に依存する即値をマスクした命令の並びで照合（`tools/porter.py`）
- PLT 13 か所: インポート名で照合（`tools/pltmap.py`、一律 +0xCD90）
- vtable・データ 24 か所: 中の関数ポインタで照合（`tools/vtmap.py`）
- bss のグローバル 5 か所: 参照しているコードを移して ADRP を読み直す
- SDK: `GetNpadStates` ×5 と `nvnBootstrapLoader` が +0x520。`nn::fs` は同じ位置
- **構造体の変化**（`tools/immdiff.py`・`chain.py`・`vtdiff.py` で全体を照合）
  - プレイヤー管理物: 自分の番号 `+0xD730/+0xD738` → `+0xDCD0/+0xDCD8`（+0x5A0）
  - エモート記録: 1 人分 2600 → 2672 バイト（勝利エモート +2140 は同じ）
  - 体（kEnVt）、カメラ、レティクル、CharacterController、PlayerDamage、ペイント管理物、シーン管理物のフィールドは同じ
- 「元の命令がこの値か」のチェック 21 件は、すべて 12.0.0 の実物と一致（`tools/apply_port.py` に旧→新の表）

## v707〜771 から復元したもの

- **敵の即時検出**: `BodyCalcHook` で毎フレーム全キャラの体（部品 +0x108）を集める `EnHkNote` / `EnHkBuild`。
  メモリ全体の走査は、フックが止まっているときの予備だけ
- **自分の座標**: ゲーム自身の `BfSelfComp` が「自分」と判定した体を最優先にし、5ms キャッシュ（svcQueryMemory の連打をやめた）
- **エイム曲線**: v771 を逆アセンブルして同じ式にした。9 点（1,4,…,25m）の PCHIP、値 1 = 0.1m 下。
  `狙う高さ = 敵の床 − 2.27 + 0.9 − 0.1 × (曲線(距離) + aimTune)`。3.4m より遠いときの近距離補正は 0
- 視点の反転ガード（CamDir3）、Y で視点リセット（0.35 秒止める）
- エイムボットは左右・上下とも「まだ画面に出ていない命令」の内部モデルを持ち、残りのずれを毎フレーム 100% 詰める（約 1 フレームで向く）
- 広場のニューススキップ（既定 ON。12.0.0: `main+0x3B5717C` / `+0x3B5845C`）
- 設定の `KV kv[24]` あふれ（→ snprintf(null) で落ちる）を修正。容量 64＋境界チェック

## まだのもの（v771 にはあった機能）

- レーザーサイト（ビームの長さ・太さ・間隔、マズルフラッシュ）
- Space Objects（足元にオブジェクトを置く、ピアノなど）
- お絵かきキャンバス（L スティックでペン、ZL 描く / ZR 消す）
- ブリンク（照準の先へ）
- 敵の体ログ（調査用）

v771 の EN バイナリはハンドオフの `compiled_latest/subsdk9_v771_en` にあります。ニューススキップと同じく、
メニューの文字列 → フラグ → フック／関数の順にたどれば復元できます。ただし v771 のゲーム側オフセットは 11.3.0 用なので、
`tools/porter.py` で 12.0.0 へ移してください。

## 入れていないもの

- セーブデータの入れ替え・削除（Inkdraw 版 700〜704）。日本語版・英語版どちらにも入っていません
- 相手の画面で同期する「浮遊」（ネットワーク同期で補間されないため不可能と結論済み）
